# Office Wi-Fi connectivity

## Networks
- `Bayview-Corp`: company laptops, uses your network username and password (certificate-based on managed devices).
- `Bayview-Guest`: visitors and personal phones; requires accepting terms each day; no access to internal systems.

## Cannot connect to Bayview-Corp
1. Turn Wi-Fi off and on, or toggle Airplane mode.
2. "Forget" the `Bayview-Corp` network and reconnect. If prompted, use your current password.
3. If you recently changed your password, the old saved password will fail and can lock your account (KB-002).
4. Restart the laptop.

## Slow Wi-Fi
- Move closer to an access point; conference rooms and the cafeteria have dedicated access points.
- Close large uploads or cloud syncs (OneDrive) during meetings.
- Run a speed test at https://speed.bayview.example and include the result when contacting IT.

## Whole floor offline
If several people on the same floor cannot connect, this is likely an outage. Ask the IT Assistant to check service status; it will raise a ticket if none exists.
