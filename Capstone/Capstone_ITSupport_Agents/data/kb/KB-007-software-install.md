# Installing software

Standard users do not have administrator rights. Approved software is installed through **Company Portal**.

## Approved software (self-service)
1. Open Company Portal from the Start menu.
2. Search for the application (for example Zoom, Slack, Python 3, Tableau Reader, 7-Zip, Notepad++).
3. Click **Install**. Installation runs in the background; a notification appears when it finishes.

## Software not in Company Portal
- Submit a software request through the IT Assistant with: application name, version, business justification, and whether a paid license is needed.
- Requests are reviewed by IT Security within 3 business days. Paid licenses also need manager approval.

## Install failed
- Restart the laptop and retry from Company Portal.
- Make sure at least 10 GB of disk space is free.
- If the error repeats, note the error code shown in Company Portal and contact the Service Desk.

Unapproved software (cracked tools, personal VPNs, browser extensions that read page data) is not allowed and is automatically removed.
