# Laptop is slow or freezing

## Quick fixes
1. Restart the laptop. Many users go weeks without restarting; updates and memory leaks build up.
2. Open Task Manager (Ctrl+Shift+Esc) and sort by CPU and Memory. Close applications using unusually high resources.
3. Check free disk space: keep at least 15% free. Empty Downloads and the Recycle Bin; set OneDrive files to "Free up space".
4. Install pending updates: Settings > Windows Update, and Company Portal > Updates.

## Browser
- Too many tabs and extensions are a common cause. Remove extensions you do not use.

## Hardware problems
- Loud fan, overheating, battery swelling, or blue screens (BSOD) more than once a week: stop using the device if the battery is swollen and contact the Service Desk for a hardware ticket. Laptops older than 4 years are eligible for replacement.

## Before contacting IT
Note what you were doing when the slowdown started and whether it happens on battery and plugged in.
